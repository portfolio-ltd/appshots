# Security policy

AppShots runs entirely in the browser. It has no server and stores nothing remotely. The only network request it makes on your behalf is the optional call to `api.anthropic.com` when you provide your own API key for AI captions.

## Reporting a vulnerability

Please **don't** open a public issue. Report it privately through [GitHub security advisories](https://github.com/portfolio-ltd/appshots/security/advisories/new). We aim to reply within a week.

Useful details: affected version or commit, steps to reproduce, and impact (for example, a way for a crafted image or sticker to run script, or a leak of the stored API key).
